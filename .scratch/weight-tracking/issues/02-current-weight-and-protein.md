# 02：目前體重進入計劃計算，蛋白質下限依 ADR 0012

**What to build:** 減重計劃的 TDEE、BMR、每週預計減重量改用**目前體重**計算，計劃卡片顯示最新值（不改任何設定、絕不自動改每日熱量目標）。蛋白質建議下限在減重計劃進行中（有計劃且目前體重 > 目標體重）改為 `max(1.4 × 基準體重, RDA 倍率 × max(起始體重, 目前體重))`；達成目標後回到 RDA 倍率 × 目前體重；沒有計劃維持「—」。目標說明文字隨情境切換，赤字期附腎功能提醒。依據見 [ADR 0012](../../../docs/decisions/0012-protein-floor-during-deficit.md)。

**Blocked by:** 01：記錄、修改、刪除體重

**Status:** ready-for-agent

- [ ] 開工前先找到 ESPEN 調整體重 0.33 的原文並核對；若與 ADR 0012 不符，停下來回報，不要照做
- [ ] 計劃卡片的 TDEE、每週預計減重量隨目前體重更新；每日熱量目標不被改動
- [ ] 蛋白質：赤字期取較大值；BMI 36.8（71 歲以上約 31.8）附近的門檻有測試；起始體重大於目前體重時用起始體重；RDA 倍率 71 歲以上為 1.2
- [ ] 基準體重：實際 ≤ 25×身高² 用實際，否則參考體重 + 0.33 ×（實際 − 參考）；結果四捨五入到整數 g
- [ ] 達成目標（目前體重 ≤ 目標）回到 RDA 倍率 × 目前體重；沒有計劃為未知（不是 0），UI 顯示「—」並提示設定計劃
- [ ] 其餘四項建議值與覆寫值規則不變；覆寫過的蛋白質目標不受影響
- [ ] 赤字期蛋白質目標的說明文字：算法、出處（如實說明 1.4 是間接依據）與「腎功能不佳者請先諮詢醫師或營養師」；維持期顯示原本的 DRIs 說明
- [ ] 過去日子的達標判定一律用現在的目標
