# 03：計劃進度改以體重計算

**What to build:** 記錄體重不再改變預計達成日（預計達成日與總天數固定，以**起始體重**、開始日與**起點每日目標**推算）。進度百分比改為（起始體重 − 目前體重）÷（起始體重 − 目標體重），限制 0–100%，體重回升時下降。計劃卡片顯示「實際比計劃線高／低 X 公斤」。最新一筆體重 ≤ 目標即顯示「已達成目標」，回升自動取消。有紀錄時計劃表單的「目前體重」預填最新紀錄且唯讀。儲存表單改性別、年齡、身高、活動量、目標不重設起始體重與開始日；另提供明確的「重新開始計劃」按鈕，以目前體重與今天為新起點。

**Blocked by:** 02：目前體重進入計劃計算，蛋白質下限依 ADR 0012
