# 03：計劃進度改以體重計算

**What to build:** 記錄體重不再改變預計達成日（預計達成日與總天數固定，以**起始體重**、開始日與目前每日目標推算）。進度百分比改為（起始體重 − 目前體重）÷（起始體重 − 目標體重），限制 0–100%，體重回升時下降。計劃卡片顯示「實際比計劃線高／低 X 公斤」。最新一筆體重 ≤ 目標即顯示「已達成目標」，回升自動取消。有紀錄時計劃表單的「目前體重」預填最新紀錄且唯讀。儲存表單改性別、年齡、身高、活動量、目標不重設起始體重與開始日；另提供明確的「重新開始計劃」按鈕，以目前體重與今天為新起點。

**Blocked by:** 02：目前體重進入計劃計算，蛋白質下限依 ADR 0012

**Status:** ready-for-agent

- [ ] 記體重前後，預計達成日與總天數相同
- [ ] 進度百分比以體重計算，回升時下降，限制在 0–100%
- [ ] 計劃線：從開始日的起始體重，依儲存計劃當下的每週預計減重量直線下降到目標；卡片顯示最新紀錄日對照計劃線的差距；每日目標之後改變不回頭改計劃線
- [ ] 最新體重 ≤ 目標顯示「已達成目標」；回升到目標之上自動回到進行中
- [ ] 「已到預計日期，請更新體重」提示保留
- [ ] 有紀錄時計劃表單的目前體重唯讀（預填最新紀錄）；沒有紀錄時照舊可填
- [ ] 儲存表單改性別、年齡、身高、活動量、目標，不動起始體重與開始日；「重新開始計劃」才重設為目前體重與今天
- [ ] 沒有體重紀錄的既有使用者行為與以前一致
- [ ] 純函式與 HTTP 測試；`npm test` 全過、`npm run build` 成功
- [ ] 手機寬度（375×812）檢視計劃卡片
