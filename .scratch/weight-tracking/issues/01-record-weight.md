# 01：記錄、修改、刪除體重（含設定頁「體重」卡片基本版）

**What to build:** 使用者在設定頁新增「體重」卡片，輸入體重（日期預設今天）按「記錄」存成**體重紀錄**；同一天再記就覆蓋。可從紀錄清單補記、修改、刪除過去的日期，不能記未來。卡片顯示「距離上次紀錄 N 天」（超過 7 天用提醒色）。沒有減重計劃也能用；朋友日誌各自一份；匯出備份包含體重紀錄。伺服器同時回傳**目前體重**（最新一筆；沒有紀錄時用計劃的體重）。詳見 `docs/specs/weight-tracking.md`、`GLOSSARY.md`。

**Blocked by:** None (can start immediately)

**Status:** in-review
