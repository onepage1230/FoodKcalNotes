# 01: 從既有餐點「再記一次」

**What to build:** 在任一餐點的詳情頁按「再記一次」，以今天的日期、現在的時間建立一筆新餐點，並開啟它的詳情頁（與背景辨識完成的自動存檔一致，之後可再改或刪除）。項目原樣複製：克數、熱量、來源、出處、營養素、`estimated` 標記與營養素是否被改過的標記都保留。不複製照片與備註；複製出來的項目不寫入食物庫、不觸發營養素補值（ADR 0004、0010）。建立餐點的端點接受可省略的時間參數（省略時用現在），供 02 的候選餐點使用。依 [spec](../../../docs/specs/repeat-meals.md) 與 [ADR 0011](../../../docs/decisions/0011-repeat-meals.md)。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 詳情頁有「再記一次」按鈕；按下後新增今天的餐點並顯示其詳情頁與提示
- [ ] 新餐點的項目與來源餐點相同（含來源、出處、營養素、`estimated`、營養素被改過的標記），名稱沿用，不含照片與備註
- [ ] 新餐點不寫入食物庫、不補營養素；來源餐點與食物庫不被修改
- [ ] 時間參數省略時為伺服器本地現在；有給時使用給定時間；日期一律為伺服器本地今天
- [ ] 來源餐點不存在回 404；時間格式不正確回 400
- [ ] 當日總量、營養素總計與連勝照常更新（HTTP 層測試）
- [ ] 朋友日誌只能複製自己日誌裡的餐點
- [ ] 用瀏覽器實際檢視詳情頁按鈕與跳轉
