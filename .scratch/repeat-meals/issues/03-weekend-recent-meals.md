# 03: 假日的「最近吃過」

**What to build:** 週六、日首頁的候選改用「最近吃過」的規則：統計 30 天內所有日子的餐點（不分平日或假日），依名稱組合合併後，依最近一次的出現時間由近到遠選取，時間用最近一次實際的時間（不用中位數），不要求至少出現 2 次。過濾與顯示規則（時間不晚於現在、前後 90 分鐘內沒有餐點、最多 5 個、依時間排列）沿用 02，點選與複製的行為不變。這樣假日和太太一起吃、內容不固定時，可挑最近吃過的最接近的一餐再改；也能挑回平日那一套。依 [spec](../../../docs/specs/repeat-meals.md) 與 [ADR 0011](../../../docs/decisions/0011-repeat-meals.md)。

**Blocked by:** 02 首頁平日候選餐點

**Status:** in-review

- [x] 週六、日使用本張的規則；週一到週五維持 02 的規則（以注入的日期測試切換）
- [x] 假日候選包含平日吃過的餐點；只出現一次的餐點也可以成為候選
- [x] 候選的時間為最近一次實際的時間，並套用 02 的「不晚於現在」與「90 分鐘內已有餐點則排除」
- [x] 純函式測試涵蓋假日規則與平日、假日切換的邊界（週五、週六、週日、週一）
- [x] HTTP 測試涵蓋假日候選查詢與點選複製
- [x] 用瀏覽器實際檢視假日首頁（以指定日期的測試資料）
