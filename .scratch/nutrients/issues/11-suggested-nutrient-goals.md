# 11: 建議營養目標：查證、計算與覆寫

**What to build:** 設定頁的減重計劃區塊顯示依國健署標準計算的每日營養目標建議值與依據：蛋白質為下限、脂肪與碳水為參考範圍、糖與鈉為上限。使用者可以逐項覆寫或恢復建議值；沒覆寫的項目在體重或每日熱量目標改變時自動重算。糖的欄位標示「總糖」並說明比對添加糖上限可能高估。

**Blocked by:** 01

**Status:** done

- [x] 查證國健署 DRIs 與每日飲食指南，把每項的公式、數字與出處寫進 ADR 0010（不使用未查證的數字）
- [x] 建議值計算是純函式，輸入計劃與每日熱量目標，輸出五項目標與類型
- [x] 糖上限依「添加糖 ≤ 每日熱量 10%」換算
- [x] 設定只存覆寫值；實際目標 = 覆寫值，否則為建議值
- [x] 設定 API 接受覆寫與清除覆寫，並驗證數值
- [x] 設定頁顯示建議值、依據、覆寫與恢復；糖的高估說明
- [x] 純函式測試涵蓋建議值計算、覆寫優先、計劃改變時只有未覆寫項目變動
