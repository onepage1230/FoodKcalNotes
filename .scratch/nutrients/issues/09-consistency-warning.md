# 09: 熱量與營養素一致性提醒

**What to build:** 結果頁在某項食物的熱量與「蛋白質×4 + 碳水×4 + 脂肪×9」差距過大時顯示提醒，只提醒、不擋下保存也不修改數值。門檻先用食藥署資料驗證，再定案並寫回 ADR 0010。

**Blocked by:** 01, 08

**Status:** done
