# 06: 食物庫存營養素，以及補值與覆蓋的例外

**What to build:** 保存餐點時，食物庫依 ADR 0010 的例外規則保存與更新營養素：新寫入的食物連同營養素與 `estimated` 一起存；既有食物的 `null` 營養素可被補上；標記為估算的營養素只能被有出處的值（網路資料、營養標示）覆蓋並移除標記；熱量、名稱與有出處的欄位永不覆蓋。食物庫畫面顯示每 100g 的五項營養素與「估」標記。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 新食物寫入時保存營養素與 `estimated`；既有寫入條件（`cache`、非命中、自動來源）不變
- [ ] 既有食物：`null` 欄位可被估算值或有出處的值補上
- [ ] 既有食物：`estimated` 中的欄位只能被有出處的值覆蓋，覆蓋後移出 `estimated`；不會被另一個估算值覆蓋
- [ ] 既有食物：熱量、名稱與有出處的營養素永不改變
- [ ] 使用者手動改過熱量或營養素的項目不參與補值
- [ ] `FRIENDS_CACHE` 關閉時，朋友日誌不新增食物也不補值
- [ ] 食物庫畫面顯示五項營養素與「估」
- [ ] 日誌模組測試涵蓋上述每一條規則；HTTP API 端對端測試：背景分析自動存檔後，餐點與食物庫的營養素正確，朋友日誌不寫入
