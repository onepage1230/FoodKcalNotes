# 05: 合併補估缺少的營養素

**What to build:** 分析完成後，熱量已有來源（營養標示、本機食物庫命中、網路資料）但仍有營養素為 `null` 的項目，同一餐合併成一次補估呼叫，只回傳營養素，填入的欄位列入 `estimated`。補估絕不改動熱量。沒有缺值時不呼叫；補估失敗時整餐照常保存，營養素保留 `null` 並附一則警告。

**Blocked by:** 03

- [x] 只補 `null` 的欄位，已有值的欄位不被改動
- [x] 補估經過既有的服務順序、備援與逾時重試
