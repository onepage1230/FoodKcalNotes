# 08: 內附資料：食藥署重新擷取與匯入格式

**What to build:** 內附的食藥署 137 筆資料補上五項營養素，數值取自政府資料開放平台的原始資料集、不修改，依每筆保留的樣品編號對應。確認國健署「熱量知多少」原始頁面是否有營養素，沒有就維持只有熱量。維護者用 `import-foods` 匯入含營養素的資料，`--dry-run` 報告含營養素的筆數。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 找到並記錄食藥署原始資料集的下載來源與版本
- [ ] 137 筆每筆的五項營養素與原始資料一致；原始資料缺值的欄位為 `null`
- [ ] 確認並記錄國健署資料有無營養素
- [ ] `import-foods` 接受選填的營養素欄位與 `estimated`；舊格式照常匯入；「名稱已存在就略過」不變
- [ ] `--dry-run` 報告含營養素的筆數
- [ ] 資料來源與授權說明同步更新擷取範圍
- [ ] 人工抽查至少 10 筆與原始資料一致

進度：第一段（匯入格式、來源調查）完成；尚待使用者確認來源後的第二段（重新擷取 137 筆、更新資料與來源說明）。
