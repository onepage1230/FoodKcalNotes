# 03: LLM 估算一次估六個數值，畫面標「估」

**What to build:** 熱量需要走 LLM 估算的項目，同一次呼叫一併估出五項營養素，全部列入 `estimated`。結果頁在估算的營養素旁標「估」，手動修改後「估」消失。不增加任何額外呼叫。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 估算呼叫的結構化輸出加入五個營養素欄位，兩種服務都帶上
- [ ] 估算出的營養素全部列入 `estimated`；估不出來的保留 `null`
- [ ] 判斷為「同一種」（`sameAs`）而命中食物庫時，不使用估算的營養素
- [ ] 結果頁在 `estimated` 中的欄位旁標「估」；手動修改後移除
- [ ] 背景自動存檔時，熱量為 LLM 估算的項目仍不寫入食物庫（既有規則不變）
- [ ] 分析流程測試涵蓋：六個數值一次回傳、`estimated` 標記、呼叫次數不變
