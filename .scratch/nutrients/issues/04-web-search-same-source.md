# 04: 網路搜尋採用同一來源的營養素

**What to build:** 網路搜尋在同一次呼叫中取得熱量與五項營養素。熱量的引用驗證（ADR 0002）通過時，同一份回應中的營養素一併採用為網路資料；驗證失敗而降級為 LLM 估算時，回應中的營養素全部捨棄，改由 03 的估算路徑取得。不為了營養素做第二次搜尋。

**Blocked by:** 03

**Status:** done
