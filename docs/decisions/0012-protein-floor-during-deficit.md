# 0012 減重期蛋白質下限：不隨體重下降，倍率提高到 1.4 g/kg

- 狀態：已採用（取代 ADR 0010「建議值的公式與出處」表中的蛋白質一列）

## 背景

ADR 0010 的蛋白質下限是「目前體重 × 1.1 g/kg（71 歲以上 × 1.2）」，出自國健署 DRIs 第八版，那是一般成人維持狀態的建議量。加入體重紀錄後，目前體重會隨減重逐步下降，下限也跟著下降，與目的相反：熱量赤字期間蛋白質是保留肌肉的關鍵，不該因為體重變輕而降低。

DRIs 第八版蛋白質章節（書頁 122）只說「以低熱量飲食減重時蛋白質之熱量百分比應該要提高」，沒有給數字（見 ADR 0010），所以倍率必須取自 DRIs 以外的來源，並如實標示依據的強度。

## 決定

**只在減重計劃進行中（有計劃且目前體重 > 目標體重）改用新公式；其餘情況維持 ADR 0010 不變。**

- 倍率：**1.4 g/kg**。
- 基準體重：取「計劃起始體重」與「目前體重」兩者較大者，再依下面的調整體重換算。計劃進行中，下限不會因減重而下降，體重回升時才跟著升。
- 調整體重：參考體重 = BMI 25 對應體重（25 × 身高 m²）。實際體重 ≤ 參考體重時用實際體重；超過時用 `參考體重 + 0.33 ×（實際體重 − 參考體重）`。
- 計劃已達成（目前體重 ≤ 目標體重）：回到 ADR 0010 的 1.1（71 歲以上 1.2）× 目前體重。
- 沒有減重計劃：維持 ADR 0010，蛋白質建議值為 `null`。
- 結果四捨五入到整數 g。使用者的覆寫值不受影響；沒覆寫的蛋白質目標在部署後會自動升高。
- 計劃進行中，蛋白質目標旁顯示一行提醒：腎功能不佳者請先諮詢醫師或營養師。不加強制上限。
- 過去日子的達標判定一律用現在算出的目標，不回頭查當時的體重。

## 依據與誠實的限制（查證日期 2026-11-05）

**沒有任何權威文件明確寫「熱量赤字期 1.4 g/kg」或「1.6 g/kg」。** 1.4 是間接支持：

- ISSN 立場聲明（Jäger 等，J Int Soc Sports Nutr 2017;14:20，[PMC5477153](https://pmc.ncbi.nlm.nih.gov/articles/PMC5477153/)）第 2 點建議每日蛋白質 1.4–2.0 g/kg 體重。1.4 是這個範圍的下緣；範圍針對運動人口，不是專為赤字期訂。
- Morton 等（Br J Sports Med 2018;52:376–384，[PMC5867436](https://pmc.ncbi.nlm.nih.gov/articles/PMC5867436/)）：總蛋白質超過約 1.6 g/kg/天後，阻力訓練增加的去脂體重不再增加。對象是健康成人，不是減重者；該文有 2020 年更正（BJSM 2020;54:e7），內容未核對。
- Helms 等（J Int Soc Sports Nutr 2014;11:20，[PMC4033492](https://pmc.ncbi.nlm.nih.gov/articles/PMC4033492/)）指出能量限制時需求更高（2.3–3.1 g/kg 瘦體重），對象是備賽的精瘦運動員，不能套用到一般人，僅作為「赤字期建議高於維持期」的佐證。

**選 1.4 而不是 1.6 的原因**：KDIGO 2024 CKD 指引（Practice Point 3.3.1.1，[官方 PDF](https://kdigo.org/wp-content/uploads/2024/03/KDIGO-2024-CKD-Guideline.pdf)）建議有進展風險的 CKD 成人避免超過 1.3 g/kg/天。1.4 在 ISSN 範圍內，離這條線最近；1.6 的保留肌肉效益也只有間接證據，不值得冒更大的差距。台灣國健署只有定性說法（腎臟病人應諮詢醫師或營養師評估蛋白質攝取量，[國健署頁面](https://www.hpa.gov.tw/Pages/Detail.aspx?nodeid=127&pid=14504)），沒有查到可核實的數字，所以數字提醒只引 KDIGO，國健署只引定性說法。

**調整體重的 0.33**：出自 ESPEN 的臨床指引（ICU 肥胖病人，以及 ESPEN/UEG 2023 肥胖合併肝病表，後者以 BMI 25 對應體重為參考，蛋白質以調整體重計）。這是**僅經搜尋摘要確認、原文未能開啟**的出處，適用情境是臨床而非一般人減重；實作前應找到原文再核對一次。曾考慮「超出部分算一半」，但找不到任何蛋白質處方指引使用 0.5，所以不用。

## 考慮過的替代方案

- **維持 1.1 g/kg，只改基準體重不隨體重下降**：出處最乾淨，但沒有回應「赤字期應提高下限」。
- **1.6 g/kg**：與 Morton 的趨平點一致，但與 KDIGO 的 1.3 差距較大，且沒有赤字期的直接證據。
- **一律用實際體重**：高 BMI 者目標偏高（例如 120 公斤 × 1.4 = 168 g），沒有指引支持。
- **熱量百分比**：DRIs 提到要提高百分比，但沒給數字，且會隨熱量目標下降，與目的相反。

## 後果

- `suggestedGoals` 需要知道：計劃是否進行中、起始體重、目前體重、身高。蛋白質之外的四項不變。
- 計劃需要穩定的「起始體重」（儲存計劃當下的體重，之後不隨體重紀錄改變）；目前體重取自體重紀錄（見 `GLOSSARY.md`）。
- 若日後國健署公布減重期的具體數字（例如第九版 DRIs），應以官方數字取代本決定的倍率。
